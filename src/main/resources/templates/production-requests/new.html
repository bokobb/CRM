Новое производство

Можно сразу указать несколько позиций — например, из одного теста сегодня решили сделать несколько разных вариантов. Замесы и штуки пересчитываются друг в друга сами. Название заявки определится автоматически по группе товара — если позиции из разных групп, будет создано несколько заявок.

Нет ни одного товара с заполненной рецептурой — сначала добавьте рецептуру на странице товара.
