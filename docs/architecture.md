# Архитектура

## Компоненты

```
 Android-приложение ─┐                         ┌─ 1cFresh (OData, Бухгалтерия КЗ)
 iPhone (/app/, PWA) ─┤  HTTPS                  │      ▲ фоновая очередь onec-queue
 Веб-интерфейс ───────┼──► Nginx :443 ──► Spring Boot :8080 ──► PostgreSQL :5434 (Docker)
 Сайт клиентов /shop ─┘   (Let's Encrypt)       │
                                                ├─► Firebase Cloud Messaging ──► push (Android, iPhone)
 WhatsApp ◄──► whatsapp-gateway (Node.js :3001) ┤   (вебхук /api/whatsapp/incoming, отправка накладных)
                                                └─► Claude API (разбор текста WhatsApp-заказа; ключ не задан)
```

Всё, кроме 1С, Firebase и Claude, работает на одной VM. Процессы:

| Процесс | Как запущен | Что делает |
|---|---|---|
| `crm-backend.service` | systemd, `gradlew bootRun --args=--spring.profiles.active=postgres`, `Restart=always` | весь backend: API, веб, /shop, /app, расписания, очередь 1С |
| `crm-postgres` | Docker, `restart: unless-stopped` | база данных |
| `crm-whatsapp-gateway.service` | systemd, `node index.js` | приём/отправка сообщений WhatsApp |
| Nginx | системный | HTTPS, прокси на :8080, раздача APK `/downloads/` |
| cron (bakhodir) | 03:00 | ежедневный `pg_dump` в `~/backups/`, хранение 14 дней |

## Backend (Spring Boot)

- **Слои:** `domain` (JPA) → `repository` → `service` → `api` (REST, JSON, JWT) / `web` (Thymeleaf, сессия).
- **Безопасность (`SecurityConfig`):** несколько цепочек фильтров:
  1. `/api/**` — JWT (`Authorization: Bearer`), без сессии; роли через `@PreAuthorize`.
  2. `/shop/**` — открыто (клиент входит по номеру телефона, сессия).
  3. `/product-images/**`, `/app/**` — публичная статика.
  4. `/**` — веб-интерфейс, вход формой, «Запомнить меня» на 30 дней.
- **Роли:** `ADMIN`, `ACCOUNTANT`, `SALES`, `WAREHOUSE_FG`, `WAREHOUSE_RAW`, `TECHNOLOGIST` (см. business.md).
- **Схема БД:** Hibernate `ddl-auto=update` — новые таблицы/колонки создаются сами при старте; NOT NULL на
  непустых таблицах и CHECK-ограничения enum-полей правятся вручную (см. operations.md).
- **Идемпотентность:** `IdempotencyFilter` + заголовок `Idempotency-Key` из приложения — повтор того же
  запроса в течение 30 минут возвращает первый ответ (защита от двойных заказов при плохой связи).
- **Расписания (`ScheduledJobs`, зона GMT+5):** проверка низких остатков (каждый час), просроченные долги
  (09:00), синхронизация остатков из 1С (каждые 5 мин), импорт реализаций/поступлений из 1С (каждые 5 мин
  с 7 до 18), импорт возвратов (каждые 5 мин), автоповтор неудачных выгрузок (каждые 10 мин 7–20).
- **Фоновая очередь 1С (`OneCQueue`):** CRM никогда не ждёт 1cFresh. Изменённый заказ/заявка/закупка/возврат
  помечается флагом `onec_pending`, после коммита один поток `onec-queue` приводит документ 1С к состоянию
  CRM. После перезапуска очередь дочищается сама (опрос раз в минуту). Подробно — onec.md.
- **PDF:** накладные (`InvoicePdfService`, по макету печатной формы 1С) и отчёт производства (PDFBox).
- **Excel:** табель сотрудников (Apache POI).

## Мобильное приложение (Flutter)

Один код для Android (APK) и веба (`flutter build web`, раздаётся backend-ом по `/app/`, на iPhone —
«На экран Домой»). Общается только с `/api/**`. Подробно — mobile.md.

## Ключевые технические решения

| Решение | Почему |
|---|---|
| 1cFresh остаётся бухгалтерией, CRM — оперативный учёт | своя 1С на сервере платная; две бухгалтерии с синхронизацией — источник расхождений |
| Документы в 1С создаются черновиками и проводятся по событию (отгрузка, оприходование, «Завершить») | бухгалтер видит всё сразу, но остатки 1С двигаются только по факту |
| Отмена = распровести (черновик), удаление = пометить на удаление | ничего не удаляется из 1С физически, история сохраняется |
| Веб-сборка приложения вне classpath (`crm.web-app.dir`), отдаётся с `no-cache` | обновляется `rsync` без пересборки backend; iPhone сразу видит новую версию |
| Цвета приложения только через тему (`context.pal`) | 15 тем, включая ночные, без правки экранов |
| JWT 12 часов, секрет в `backend.env` | приложение работает без повторного входа всю смену |
