# Задание: соцсети в полосе контактов — значок и название в строку

Задание для Claude Code в проекте CRM «Юг Сладости». Сначала прочитай `CLAUDE.md`; его правила важнее этого текста.
Правка небольшая: один пункт полосы контактов, адрес в соседнем пункте, строка в подвале и проверка шапки.

## Что сейчас не так

- **Пункт соцсетей.** Пункт «Instagram / TikTok» устроен не так, как остальные: крупно стоит ник `@yug_sladosti`,
  под ним две мелкие подчёркнутые красные ссылки «Instagram» и «TikTok». В остальных пунктах значения набраны
  жирным тёмным текстом, поэтому этот пункт выглядит чужим.
- **Адрес.** Строка заканчивается на «ул.», а «Жусипбека Елебекова, 128» уезжает на следующую.

## Как должно быть

Пункт **«Соцсети»** — так решил владелец:

```
Соцсети
(значок Instagram)  Instagram
(значок TikTok)     TikTok
```

- **Подпись** «Соцсети» — мелкая, как у остальных пунктов полосы.
- **Под подписью две строки-ссылки.** В каждой маленький тёмный кружок со значком сети и сразу рядом название
  жирным тёмным текстом, как номера телефонов. Ника в этом пункте нет.
- **При наведении** название подчёркивается, кружок становится красным.
- **Значки — официальные, белые одноцветные:**
  - Instagram — из Meta Brand Resource Center (раздел Instagram, glyph);
  - TikTok — из брендбука TikTok (иконка для ссылки на аккаунт).

  Скачай SVG и вставь в разметку прямо в коде, размер 16×16, `aria-hidden="true"`. Не перерисовывай,
  не искажай и не перекрашивай сверх того, что разрешают правила бренда. Если цвет в SVG задан явно — замени его
  на `currentColor`, если это разрешено правилами бренда: тогда значок берёт белый цвет кружка.
  На макете в кружках стоят временные значки (камера и нота); их на сайт не переносить.
- **Стили,** которые добавлялись для мелких подчёркнутых ссылок, убери.

```html
<li class="c-soc">
  <span class="c-t"><span class="c-l">Соцсети</span><span class="c-net"><a class="c-net-a" href="https://www.instagram.com/yug_sladosti" target="_blank" rel="noopener"><span class="c-net-i" aria-hidden="true">{белый значок Instagram, SVG 16×16}</span>Instagram</a><a class="c-net-a" href="{ссылка на TikTok — та, что уже стоит на сайте}" target="_blank" rel="noopener"><span class="c-net-i" aria-hidden="true">{белый значок TikTok, SVG 16×16}</span>TikTok</a></span></span>
</li>
```

```css
/* соцсети: под подписью по строке на сеть — маленький круглый значок и название рядом */
.c-net{display:grid;gap:4px;margin-top:4px}
.c-net-a{display:inline-flex;align-items:center;gap:10px;width:fit-content;min-height:34px;font-weight:600;line-height:1.35;text-decoration:none}
.c-net-i{display:grid;place-items:center;flex:none;width:30px;height:30px;border-radius:50%;background:var(--ink);color:#fff;transition:background-color .15s}
.c-net-a:hover{text-decoration:underline}
.c-net-a:hover .c-net-i{background:var(--crimson)}
@media (prefers-reduced-motion:reduce){
  .c-net-i{transition:none}
}
```

**Адрес** — с неразрывными пробелами после коротких слов, чтобы строка не заканчивалась на «г.», «ж/м» или «ул.»:

```html
<span class="c-v">г.&nbsp;Шымкент, ж/м&nbsp;Исфиджаб, ул.&nbsp;Жусипбека Елебекова,&nbsp;128</span><span class="c-sub">(ул.&nbsp;Елебекова,&nbsp;135а, Енбекшинский&nbsp;район)</span>
```

Так же — адрес в подвале (`.foot-addr`).

**Подвал.** В колонке «Связаться» под Instagram добавь TikTok тем же стилем, что Instagram:

```html
<a class="foot-link" href="https://www.instagram.com/yug_sladosti" target="_blank" rel="noopener">Instagram <small>@yug_sladosti</small></a>
<a class="foot-link" href="{ссылка на TikTok}" target="_blank" rel="noopener">TikTok <small>{ник в TikTok}</small></a>
```

Если на сайте уже есть страница `/contacts` с той же полосой контактов — поправь пункт и там.

## Заодно проверь шапку

В шапке теперь пять разделов (добавились «Вакансии»), а бургер включается только с 900 px. На макете с пятью
пунктами на ширине 901–915 px шапка становится шире экрана, и вся страница прокручивается вбок. Проверь у себя
на 901–960 px; если так же — добавь после остальных `@media`:

```css
@media (max-width:960px){
  .nav{display:none}                  /* пять разделов помещаются примерно с 916 px; уже 960 — бургер */
  .burger{display:inline-flex}
}
```

## Как проверить

- [ ] На 1440 и 1920 в пункте «Соцсети» две строки: кружок со значком и название рядом, ника нет;
      при наведении название подчёркивается, кружок краснеет.
- [ ] Ссылки открывают Instagram и TikTok в новой вкладке.
- [ ] Адрес нигде не переносится так, что строка заканчивается на «г.», «ж/м» или «ул.».
- [ ] На 768 полоса два на два, на 390 и 320 — списком. Горизонтальной прокрутки нет.
- [ ] В подвале в «Связаться» есть TikTok.
- [ ] Шапка на ширине 901–960: страница не прокручивается вбок, меню свёрнуто в бургер.
